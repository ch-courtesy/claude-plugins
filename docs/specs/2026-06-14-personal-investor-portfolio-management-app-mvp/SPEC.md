# 개인 투자자 포트폴리오 관리 앱 MVP

## 요약

- 국내·미국 주식 개인 투자자를 위한 반응형 웹 앱을 만든다.
- 사용자는 종목, 보유수량, 평균단가를 직접 등록한다.
- 주문 실행과 거래내역 관리는 지원하지 않는다.
- 핵심 가치는 빠른 포트폴리오 등록, 현재 평가손익 확인, 목표 비중 기반 리밸런싱이다.
- MVP 성공 지표는 `가입 후 포트폴리오 등록 완료율`이다.

## 리서치 결론

- Sharesight는 성과·세금 보고, Snowball Analytics는 배당·리밸런싱, Delta는 쉬운 통합 자산 조회에 강점이 있다.
- 거래내역이 없으므로 정확한 누적·실현·기간 수익률은 계산할 수 없다. MVP에서는 현재 평가손익만 제공한다.
- 광고는 금융 화면의 신뢰성과 집중도를 떨어뜨리고 초기 트래픽으로는 수익성이 낮다. 무료 MVP로 사용성을 검증한 후 구독 모델을 검토한다.
- 무료 배당 API는 국내 종목 누락과 상업적 재표시 제한 위험이 있다. 배당 데이터는 실험 기능으로 표시한다.

## 핵심 기능

- 종목 검색 및 등록: 토스증권 지원 종목 중 국내·미국 주식 등록
- 보유 정보: 수량, 평균단가, 목표 비중 직접 입력
- 포트폴리오 현황: 평가금액, 평가손익, 수익률, 종목·시장·통화별 비중
- 리밸런싱: 현재 비중과 목표 비중 차이, 목표 달성을 위한 매수·매도 참고 금액
- 종목 상세: 현재가, 일봉 차트, 종목 기본 정보, 거래정지·투자경고 정보
- 배당: 무료 외부 API 기반 예상 배당 일정과 연간 예상 배당금, 데이터 정확도 경고 표시

## 데이터·기술 설계

- 토스증권 API는 백엔드에서만 호출하고 OAuth 자격증명과 토큰을 서버에 보관한다.
- 현재가는 여러 종목을 최대 200개씩 묶어 조회하고 짧게 캐시한다.
- 종목 검색용 목록은 별도 종목 마스터 DB로 관리한다. 토스 API는 전체 종목 검색을 제공하지 않는다.
- 포트폴리오 모델은 사용자, 포트폴리오, 보유종목, 목표비중으로 구성한다.
- 모든 포트폴리오 합계는 KRW 기준으로 표시하고 미국 주식은 토스 환율 API로 환산한다.
- 배당 공급자는 교체 가능한 인터페이스로 분리한다. 무료 API 실패·누락 시 배당 영역만 비활성화한다.
- 실시간 차트는 지원하지 않는다. 현재가는 REST 폴링으로 갱신하고 일봉 차트를 기본 제공한다.

## 검증 계획

- 사용자가 가입 후 3분 이내 첫 종목을 등록하고 포트폴리오 화면을 확인할 수 있어야 한다.
- 국내·미국 종목 혼합 포트폴리오의 평가금액과 KRW 환산값을 검증한다.
- 목표 비중 합계 검증과 리밸런싱 금액 계산을 테스트한다.
- 휴장일, 오래된 시세, 환율 API 실패, 상장폐지·거래정지 종목을 처리한다.
- 배당 데이터 누락·공급자 장애 시 포트폴리오 핵심 기능이 정상 동작하는지 확인한다.
- 핵심 지표로 가입, 종목 검색, 첫 보유종목 등록, 포트폴리오 등록 완료 이벤트를 수집한다.

## 주요 위험과 기본 결정

- 거래내역이 없으므로 “총수익률” 표현을 사용하지 않고 “현재 평가손익”으로 표시한다.
- 배당 데이터는 무료 공급자의 상업 이용 조건을 확인한 후에만 노출한다.
- 투자 추천이나 자동 매매 기능은 제공하지 않으며, 리밸런싱 결과는 참고 정보로 표시한다.
- 초기 수익화는 하지 않고 등록 완료율과 재방문 데이터를 확보한 후 구독 모델을 검토한다.

# 인터뷰 동적 폼으로 태스크 추가

## 무엇을 만들 것인가

"태스크 추가" 동작에서 Claude Code의 `spec` 스킬을 구동해, 스킬이 진행하는 명확화 인터뷰를 **확장 안의 동적 폼**으로 렌더하고 사용자가 폼으로 답하면 그 답을 스킬에 되돌려 인터뷰를 이어가는 흐름을 만든다. 스킬이 인터뷰 중 던지는 구조화된 질문(질문 텍스트·헤더·선택지·복수선택 여부)을 가로채, 그 스키마대로 폼을 동적으로 생성한다. 사용자가 폼을 제출하면 선택한 답을 스킬에 회신하고, 스킬은 다음 질문으로 진행한다. 인터뷰가 끝나 SPEC 본문이 생성되면, 그 본문을 body로 하여 활성 백엔드에 새 태스크를 만든다(태스크 생성은 골격 SPEC의 데이터소스 계약 호출).

## 목적 (왜)

새 태스크를 추가할 때 즉흥적 한 줄 제목이 아니라, 명확화 인터뷰를 거친 자기완결 SPEC을 본문으로 삼게 하기 위해서다. 인터뷰를 편집기 안 동적 폼으로 받으면, 터미널로 나가지 않고 카드 추가와 같은 자리에서 의도를 구조화할 수 있다.

## 완료 조건

- "태스크 추가"를 시작할 때, 시스템은 사용자가 준 자연어 설명으로 `spec` 스킬의 인터뷰 세션을 시작해야 한다.
- 스킬이 인터뷰 중 구조화된 질문을 던질 때, 시스템은 그 질문이 실행되기 전에 가로채 질문 텍스트·헤더·선택지·복수선택 여부대로 동적 폼을 렌더해야 한다.
- 사용자가 폼을 제출할 때까지, 시스템은 인터뷰 세션을 그 질문에 멈춘 채 같은 세션·맥락을 유지해야 한다.
- 사용자가 폼을 제출할 때, 시스템은 선택한 답을 스킬에 회신하고 스킬이 다음 질문으로 진행하게 해야 한다.
- 질문에 선택지 외 직접 입력이 필요하면, 시스템은 사용자가 자유 입력으로 답할 수 있게 하고 그 값을 답으로 회신해야 한다.
- 스킬이 구조화된 질문이 아닌 자유 텍스트로 물을 때, 시스템은 그 원시 프롬프트를 사용자에게 그대로 보여주고 자유 입력으로 답을 받아 세션에 회신해야 한다(인터뷰가 멈추지 않아야 한다).
- 인터뷰가 끝나 SPEC 본문이 생성되면, 시스템은 그 본문을 body로 하여 활성 백엔드에 새 태스크를 만들고 새 카드가 뷰에 나타나게 해야 한다.
- 인터뷰 도중 사용자가 취소하면, 시스템은 세션을 종료하고 활성 백엔드에 어떤 태스크도 만들지 않아야 한다.
- 인터뷰 구동에 필요한 자격증명이 없거나 세션이 실패하면, 시스템은 그 실패를 관찰 가능하게 알리고 태스크를 만들지 않아야 한다.

## 범위

포함:
- "태스크 추가" 진입점과 자연어 설명 입력 받기.
- `spec` 스킬 인터뷰 세션 구동과, 구조화된 질문을 실행 전에 가로채는 연동.
- 가로챈 질문 스키마(텍스트·헤더·선택지·복수선택)대로 동적 폼 렌더.
- 폼 제출 → 선택/직접입력 답을 세션에 회신 → 다음 질문 진행.
- 인터뷰 산출 SPEC 본문을 body로 활성 백엔드에 태스크 생성.
- 취소·자격증명/세션 실패 처리.

비-목표 / 제외:
- 데이터소스의 태스크 생성 로직 자체(별도 SPEC: 골격·데이터소스 추상화가 단일 출처 — 본 흐름은 그 생성 능력을 호출).
- 카드 뷰 렌더(별도 SPEC: 상태 카드 뷰).
- 생성 후 구현 단계(dispatch/loop) 자동 연계 — v1 비목표.
- `spec` 스킬 자체의 인터뷰 로직 변경 — 본 흐름은 스킬을 구동·연동만 한다.

## 검증

이 SPEC의 인수 바는 위 **완료 조건**이다. 각 조건이 관찰 가능하게 충족되면 충족된 것으로 본다. 검증을 실행하는 진입 명령은 SPEC이 아니라 프로젝트 규칙(`rules/`)이 단일 출처로 정의한다.

## 제약

- 인터뷰 구동은 Claude Agent SDK를 사용하고, 구조화된 질문 가로채기는 SDK의 도구 사용 가로채기(실행 전 일시정지 후 프로그램적 응답) 메커니즘으로 한다 — 단방향 출력만 주는 헤드리스 CLI 경로는 쓰지 않는다(폼 회신 채널이 없기 때문).
- 동적 폼으로 렌더하는 질문은 스킬이 인터뷰에서 던지는 구조화된 질문(`AskUserQuestion` 류) 스키마를 따른다.
- 한 인터뷰의 여러 질문은 하나의 세션 안에서 순차로 멈췄다 이어가며, 폼 제출 전까지 콜백이 대기한다.
- 태스크 생성은 직접 백엔드를 호출하지 않고 골격 SPEC의 데이터소스 계약을 호출한다.

## 위험

- Agent SDK는 `ANTHROPIC_API_KEY`(또는 Bedrock/Vertex 자격증명)를 요구하며 claude.ai 로그인을 지원하지 않는다 — 사용자가 API 키를 갖고 있어야 흐름이 성립한다. 자격증명 부재를 명시적 실패로 처리해 완화한다.
- 인터뷰 질문이 선택지 없는 순수 서술 답을 요구할 수 있어, 동적 폼이 선택지형뿐 아니라 자유 입력형도 지원해야 한다(완료 조건에 반영).
- SDK 도구 가로채기로 잡히는 것은 스킬이 구조화된 질문 도구로 던지는 질문뿐이다. 스킬이 자유 텍스트로 묻는 경로가 있을 수 있으므로, v1은 그 경우 원시 프롬프트를 그대로 표시하고 자유 입력으로 답받는 폴백을 갖춘다(완료 조건에 반영) — 구조화 질문 전제에만 의존하지 않는다.

# brainstorm

roundtable 플러그인의 브레인스토밍 스킬. 사람이 이 폴더를 탐색할 때 빠르게 정체·용도·호출을 파악하도록 돕는 안내서다. 동작 명세의 단일 진실 출처는 [`SKILL.md`](./SKILL.md)이며, 이 문서는 그 계약을 복제하지 않고 가리킨다.

## 무엇인가 (정체)

메인 세션을 **세션 책임자**로 유지한 채 새로운 아이디어·대안·기회 영역을 폭넓게 탐색하는 스킬이다. 성급한 단일 결론이 아니라 추적 가능한 **복수 후보군**과 검증 계획을 산출한다. 이미 정해진 대안의 판정·이해관계 합의가 목표라면 `roundtable` 스킬을 대신 쓴다.

## 언제 사용하는가 (활성화 조건)

사용자가 브레인스토밍, 아이디어 발산, 콘셉트 탐색, 대안 생성, 아이디어 검증, 또는 진행 중 세션의 재개·상태 확인을 요청할 때 활성화된다.

## 어떻게 부르는가 (호출)

`Skill(skill="brainstorm", args="<subcommand> [<args>]")` 형태로 호출한다. 서브커맨드:

- `start <주제>` — 새 브레인스토밍 시작 (인자가 없으면 기본값)
- `resume <session-id>` — 기록된 다음 행동부터 재개
- `status [session-id]` — 상태·산출물·다음 행동 보고 (읽기 전용)

산출물은 `.brainstorm/<session-id>/` 아래에 누적된다.

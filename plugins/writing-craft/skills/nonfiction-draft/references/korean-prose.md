# 한국어 표기·문체

출처의 설명을 작업 규칙으로 재구성한 작법 도구다. 구조·비율은 검증된 표준이 아니며 실패 신호는 AI 판별 근거가 아니다.

## 한국어로 쓸 때 별도로 정할 사항

영어권 방법론을 한국어 지시문으로 옮길 때는 아래 항목을 별도 편집 규칙으로 둔다. 문장 부호는 국립국어원 규범을 근거로 하고, 시제·어미·호칭의 운영 방식은 편집 운영 제안으로 구분한다. [K1][k1]

| 문제 | 구체 규칙 | 점검 방법 |
|---|---|---|
| 서술체 혼용 | 본문의 기본을 해라체·하십시오체·해요체 중 선택한다. 대사·인용·의도된 화자 변화는 별도로 허용한다 | 문단별 종결형을 추출하되 인용문을 제외한다 |
| 호칭·높임의 기준 | 인물의 첫 소개와 이후 지칭을 정한다. 특정 인물에게만 이유 없이 과도한 존칭을 붙이지 않는다 | 동일 인물·직함의 표기와 높임을 대조한다 |
| 사물 높임 | 독자에게 공손하게 말하는 것과 사물 자체를 높이는 것을 구별한다 | “가격이 높으십니다”, “기능이 있으세요” 같은 후보를 점검한다 |
| 회상의 시제 | 사건 당시의 과거, 현재의 성찰, 일반적 설명을 구분한다. 현장감을 위한 현재형은 전환 지점을 명확히 한다 | 시제 변화가 시간·관점 변화와 대응하는지 읽는다 |
| 한국어의 주어 생략 | 행위자가 바뀌거나 여러 인물이 등장하면 필요한 주어를 복원한다 | 연속 문장의 행동 주체를 표시해 모호한 곳을 찾는다 |
| 은/는·이/가 | 기계적으로 바꾸지 않는다. 대조·화제·새 정보의 차이를 확인한다 | 조사 교체로 초점이 달라지는지 문맥 안에서 판단한다 |
| 문장 끝 반복 | ‘것이다·수 있다·필요하다·했다’ 반복은 수정 후보로 탐지한다. 종결형만 바꾸지 말고 문장 기능을 확인한다 | 같은 끝말의 연속을 표시하고 설명·판단의 중복을 읽는다 |
| 대사 부호 | 서사 속 직접 대화와 직접 인용에는 큰따옴표를 쓴다 | 짝 불일치와 인용 범위를 확인한다 |
| 인용 속 인용·생각 | 인용 안의 인용, 마음속으로 한 말을 적는 경우에는 해당 작은따옴표 용법을 적용한다 | 직접 발화·내적 발화·강조를 구분한다 |
| 인용문 마침표 | 직접 인용문 끝의 마침표는 원칙과 허용 범위를 확인하고 문서 안에서 일관되게 처리한다 | 마침표 생략을 일괄 오류로 판정하지 않는다 |
| 간접 인용 | 요약한 말은 간접 인용으로 쓴다. 직접 인용과 인용 조사·시점을 무심코 섞지 않는다 | 원문 표현과 화자의 요약을 대조한다 |
| 작품명·글 제목 | 책·신문 등과 개별 글·작품의 표기 방식을 정하고 일관되게 쓴다 | 이 표기안처럼 책은 『 』, 개별 글은 「 」로 통일할 수 있다 |

동일 어미가 세 번 나온다는 이유만으로 감점하지 않는다. 논증의 병렬 구조나 서사의 리듬에서는 반복이 효과적일 수 있다. 어미 다양성을 위해 평서문을 불필요한 질문·감탄으로 바꾸지도 않는다.

한국어 수필의 ‘담백함’, ‘여운’, ‘우리말다운 문장’은 유용한 비평어일 수 있지만 그대로는 채점하기 어렵다. 다음처럼 관찰 가능한 질문으로 바꾼다.

- 담백한가 → 감정어를 거듭 덧붙이지 않고 상황과 판단을 전달하는가?
- 여운이 있는가 → 마지막 이미지·행동이 앞의 질문과 연결되면서 추가 해석의 여지를 주는가?
- 우리말다운가 → 주어·서술어·조사·수식 범위가 분명하고 해당 화자의 말로 자연스러운가?

이를 한국 수필 전체의 정설이라고 부르지 않는다. 특히 『문장강화』 원문을 대조하기 전에는 이태준의 표현으로 귀속하지 않는다. [K2][k2]

## 출처와 확인 범위

2026-11-15 조사 기록이다. 본문 확인·일부 확인·확인 못 함을 아래 범위대로 구분한다. 책 전체를 확인했다는 뜻이 아니다.

- **K1. 국립국어원, 「한국어 어문 규범」, 한글 맞춤법 부록 ‘문장 부호’.**  
  직접 대화·인용, 인용 속 인용, 마음속 말, 인용문 마침표와 작품명 표기 관련 규정 확인.  
  [공식 규범][k1]

- **K2. 한국민족문화대백과사전, 「문장강화」.**  
  이태준의 저작에 관한 연구자 집필 2차 자료. 구성과 문장론의 특징 확인. 위키문헌의 관련 장 링크는 미작성 상태여서 수필·서두·결사 장의 원문은 확인 못 함.  
  [백과 항목][k2] · [원문 확보를 시도한 위키문헌 목차](https://ko.wikisource.org/wiki/문장강화)

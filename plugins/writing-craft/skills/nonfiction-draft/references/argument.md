# 논설문·주장형 칼럼·사설

출처의 설명을 작업 규칙으로 재구성한 작법 도구다. 구조·비율은 검증된 표준이 아니며 실패 신호는 AI 판별 근거가 아니다.

### 핵심: 자료와 주장의 연결 전제

Toulmin 모델은 논증을 주장·자료·보증·뒷받침·한정·반박 요소로 분석한다. 특히 **보증은 자료가 왜 그 주장을 지지하는지 연결하는 전제**다. 출처가 많아도 이 연결이 없으면 논증이 완성되지 않는다. [A1][a1]

예를 들어 다음은 방법 설명용 가상 논증이다.

> 야간 이용이 늘었다 → 도서관 운영 시간을 늘려야 한다.

여기에는 ‘증가한 야간 수요를 현재 운영 방식으로 충족하기 어렵다’, ‘운영 연장이 다른 대안보다 적절하다’ 같은 전제가 숨어 있다. 실제 글에서는 비용·인력·다른 공간의 활용 가능성을 검토해야 한다. 수요 증가 자료만으로 정책 결론 전체를 입증했다고 보지 않는다.

### 구조 템플릿

**A. Toulmin 기반 설계표**

| 요소 | 초안 전에 작성할 내용 |
|---|---|
| 주장 | 누구에 대해, 어떤 조건에서, 무엇이 타당한가 |
| 자료 | 그 판단을 뒷받침하는 확인 가능한 사실 |
| 보증 | 이 자료를 받아들이면 왜 그 주장으로 가는가 |
| 뒷받침 | 보증 자체를 지지하는 연구·원리·합의 |
| 한정 | 어느 정도 확신하며 어디까지 적용하는가 |
| 반박·예외 | 어떤 조건에서는 성립하지 않거나 수정되는가 |

이 표는 논증을 설계·점검하는 도구다. 글의 문단 순서를 여섯 칸대로 고정하지 않는다. [A1][a1]

**B. 고전 수사학의 기능별 구성**

> 관심과 신뢰 형성 → 배경·쟁점 → 주장과 논의 범위 → 입증 → 반론 검토 → 판단·행동의 의미

Purdue의 현대적 교육 자료가 정리한 고전 구성이다. 아리스토텔레스 한 사람의 고정된 ‘여섯 문단 공식’으로 소개하지 않는다. [A2][a2]

**C. 칼럼·사설용 압축 구성**

> 지금 논의할 계기 → 핵심 판단 → 문제 진단 → 근거와 대안 → 중요한 반론·양보 → 요구 또는 판단 기준

Harvard Kennedy School의 칼럼 구조를 한국어 초안용으로 압축한 것이다. 원자료도 구조 변경을 허용한다. 문단 수는 글 길이와 쟁점에 맞춘다. [A6][a6]

성찰형 칼럼은 개인의 사고 과정을 중심에 둘 수 있다. 주장형 칼럼은 필자의 판단을, 사설은 해당 매체·조직의 입장을 책임 있게 밝혀야 한다. 실제 사설 작성에서는 발행 주체가 승인한 입장과 표현 관행을 별도 입력으로 받는다.

### 오류 후보와 수정 지시

| 오류 후보 | 의심할 신호 | 다시 써야 할 질문 |
|---|---|---|
| 성급한 일반화 | 개인 사례 몇 개로 전체 집단을 단정한다 | 이 사례가 전체를 대표한다는 근거는 무엇인가? |
| 잘못된 인과 | 선후·상관관계만으로 원인을 확정한다 | 작동 경로와 다른 원인은 검토했는가? |
| 허수아비 논증 | 상대를 극단적 주장자로 요약한다 | 실제 상대의 가장 강한 이유는 무엇인가? |
| 거짓 양자택일 | A를 택하지 않으면 곧바로 B라고 한다 | 중간안·복합안·다른 대안은 없는가? |
| 인신공격 | 주장의 타당성을 인물의 결함으로 판단한다 | 그 결함이 해당 주장·증거와 관련되는가? |
| 부적절한 권위 | 유명인의 발언을 전문 증거로 쓴다 | 해당 분야의 지식과 검증 근거가 있는가? |
| 순환 논증 | 결론을 다른 표현으로 근거에 넣는다. 논쟁 대상을 결론이 들어간 말로 정의한다(예: '가치를 더하지 않는 대량 생성') | 결론을 가정하지 않고도 근거가 성립하는가? 상대가 실제로 하는 일로 정의해도 결론이 서는가? |
| 미끄러운 경사 | 작은 변화가 파국으로 이어진다고 한다 | 각 연결 단계의 가능성과 증거는 무엇인가? |
| 잘못된 유추 | 한 가지 유사점으로 다른 속성까지 같다고 본다 | 결론에 중요한 차이를 누락하지 않았는가? |
| 쟁점 이탈 | 반론에 답하는 대신 다른 문제를 제기한다 | 원래 판단해야 할 질문에 답했는가? |

위 목록은 UNC의 오류 자료를 편집 질문으로 재구성했다. 표현 하나만으로 오류를 확정하지 않는다. 예컨대 전문가의 발언을 인용하는 행위 자체가 권위의 오류는 아니다. [A5][a5]

### 데이터·인용의 최소 기록 단위

자료 조사 단계에서 다음 기록을 유지한다.

> 주장 ID / 원자료 URL / 발행·조사 시점 / 모집단·표본 / 지표 정의·단위 / 원문 수치·발언 / 글에서의 해석 / 적용 한계

이는 OSR의 출처·맥락·한계 공개 원칙과 UNC의 근거 해석 지침을 초안 작업용으로 결합한 것이다. [A8][a8] [A4][a4]

- **분모를 확인한다.** “불만 100건”만으로 악화라고 단정하지 않는다. 이용자 수와 수집 경로가 달라졌을 수 있다.
- **변화율과 퍼센트포인트를 구분한다.** 가상 수치로 20%에서 30%는 10%포인트 증가이며, 상대 증가율은 50%다.
- **단순 평균의 대표성을 확인한다.** 집단별 차이가 결론에 중요하면 분포나 하위 집단을 살핀다.
- **수치 옆에 중요한 한계를 둔다.** 제목·본문은 단정하고 멀리 떨어진 각주만 한정하지 않는다.
- **인용의 문맥을 보존한다.** 조건절·부정·불확실성 표현을 삭제해 더 강한 주장으로 만들지 않는다.
- **요약과 직접 인용을 나눈다.** 번역·축약한 표현을 원문 그대로의 발언처럼 따옴표 안에 넣지 않는다.

앞의 세 항목은 초안용 데이터 편집 점검이다. 모든 수치를 본문에 다 적으라는 뜻은 아니다. 독자의 결론을 바꿀 수 있는 조건을 남긴다.

### 흔한 실패와 신호

| 실패 | 초안에서 보이는 신호 | 수정 방법 |
|---|---|---|
| 주제 소개로 끝남 | “중요하다·고민해야 한다”만 반복한다 | 논쟁 가능한 판단을 한 문장으로 쓴다 |
| 근거 목록형 | 숫자·인용 뒤에 곧바로 다음 자료가 나온다 | 각 자료가 지지하는 하위 주장을 설명한다 |
| 허술한 반론 | “변화를 두려워하는 사람도 있다” | 비용·실현 가능성·권리 충돌 등 실제 쟁점을 다룬다 |
| 가짜 균형 | 증거 수준이 다른 견해에 같은 무게를 준다 | 근거의 질과 불확실성을 비교한다 |
| 도덕적 비난으로 대체 | 반대자가 무지하거나 이기적이라고 한다 | 인물 평가를 빼고 논리와 자료에 답한다 |
| 숫자 권위화 | 연도·대상 없는 정밀한 수치가 등장한다 | 원자료를 찾고 확인 전에는 삭제·보류한다 |
| 무책임한 처방 | 실행 주체·비용·부작용이 없다 | 제안을 행동 단위로 좁히고 대안과 비교한다 |

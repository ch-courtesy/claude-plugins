# 리뷰·비교 글

출처의 설명을 작업 규칙으로 재구성한 작법 도구다. 구조·비율은 검증된 표준이 아니며 실패 신호는 AI 판별 근거가 아니다.

### 핵심: 평가 기준과 증거에 따른 판단

Google의 리뷰 지침은 사용자 관점, 직접 경험의 증거, 중요한 판단 요소, 장단점, 대안, 특정 용도에 적합한 이유를 강조한다. 이는 Google 검색의 리뷰 콘텐츠 작성 지침이며, 모든 문학·예술 비평의 보편 이론이나 검색 노출 보장으로 취급하지 않는다. [R1][r1]

상품·도구 리뷰와 작품 리뷰는 증거의 형태가 다르다.

| 구분 | 상품·서비스·도구 | 책·영화·공연 등 작품 |
|---|---|---|
| 핵심 질문 | 어떤 사용 조건에 적합한가 | 무엇을 시도했고 어떤 효과를 냈는가 |
| 주요 증거 | 측정값·사용 기록·실패 사례 | 장면·문장·형식·구성의 구체적 분석 |
| 비교 기준 | 비용·성능·제약·운영 조건 | 형식·주제 구현·장르 관습·미학적 효과 |
| 피해야 할 환원 | 사양이 높으면 무조건 우수 | 취향에 맞으면 무조건 우수 |

### 구조 템플릿

**A. 단일 리뷰**

> 대상·검토 범위 → 짧은 판단 → 사용자와 평가 기준 → 직접 확인한 증거 → 장점·손실 → 대안 → 추천·비추천 조건

**B. 선택을 돕는 비교 글**

> 선택 상황 → 후보 포함·제외 기준 → 비교 방법·조건 → 공통 기준표 → 중요한 차이의 해석 → 사용자별 추천 → 미확인 항목

**C. 작품 리뷰**

> 핵심 평가 → 작품의 시도·필요한 맥락 → 구체적 장면·표현 분석 → 성취와 한계 → 관련 작품과 비교 → 어떤 독서·감상 경험을 주는가

세 구조 모두 초안 작성용으로 재구성한 틀이다. 작품 리뷰에 총점이나 구매 추천을 강제하지 않는다. 비교 글도 모든 경우에 승자를 정할 필요는 없다. 정보가 부족하면 판단 보류가 유효한 결론이다.

### 시니어의 규칙 14개

| 번호 | 작성 규칙 | 점검 질문·출처 |
|---|---|---|
| R-01 | 평가 전에 독자의 선택 상황을 적는다. ‘좋은 제품’ 대신 사용 목적·예산·중요한 제약을 정한다. | 누구에게 무엇이 좋아야 하는가? [R1][r1] |
| R-02 | 후보를 넣고 뺀 이유를 밝힌다. 다른 가격대·용도의 후보를 섞으면 비교 목적을 설명한다. | 비교 집합이 결론을 유도하도록 구성되지 않았는가? 비교 목적의 중요성에서 확장. [R2][r2] |
| R-03 | 기준은 제품의 기능 목록보다 독자의 결정 요인에서 뽑는다. 중요하지 않은 차이에 같은 지면을 쓰지 않는다. | 이 차이가 실제 선택을 바꾸는가? [R1][r1] |
| R-04 | 모든 후보에 같은 질문을 적용한다. 가능한 한 같은 조건으로 시험하고, 불가능하면 조건 차이를 공개한다. | 표의 빈칸이 장점·단점으로 오해되지 않는가? [R2][r2] |
| R-05 | 직접 사용·측정·문서 확인·타인 평가를 구분한다. 사용하지 않았다면 사용한 사람의 목소리로 쓰지 않는다. | 이 문장의 판단은 어디서 왔는가? 직접 경험 증거 지침에서 재구성. [R1][r1] |
| R-06 | 직접 경험은 확인 가능한 기록과 연결한다. 사진 개수보다 판단을 뒷받침하는 장면·로그·측정 조건을 남긴다. | 독자가 체험 주장과 평가의 연결을 볼 수 있는가? [R1][r1] |
| R-07 | 숫자를 쓰면 측정 환경·단위·방법을 함께 기록한다. 제조사 수치와 자체 측정값을 같은 종류처럼 합치지 않는다. | 다른 사람이 결과 차이의 원인을 이해할 수 있는가? 측정 지침의 실행 규칙. [R1][r1] |
| R-08 | 각 장점을 사용 결과로 번역한다. 사양이 무엇인지 외에 그 차이가 누구에게 유용한지 설명한다. | 기능 이름을 지워도 이점이 설명되는가? [R1][r1] |
| R-09 | 단점은 의사결정에 미치는 영향을 쓴다. 사소한 흠 하나로 공정성을 연출하지 않는다. | 어떤 사용자에게 얼마나 중요한 손실인가? [R1][r1] |
| R-10 | ‘최고’라는 표현에는 비교 범위·기준·직접 근거를 붙인다. 특정 용도 최고와 전체 최고를 구분한다. | 다른 기준에서도 같은 결론이라고 과장하지 않았는가? [R1][r1] |
| R-11 | 점수 합산은 필요한 경우에만 쓴다. 가중치와 점수 구간을 먼저 정의하고, 치명적 제약은 총점과 별도로 처리한다. | 지원되지 않는 필수 기능이 다른 장점에 묻히는가? 기준 선택 원칙을 확장한 설계 제안. [R2][r2] |
| R-12 | 작품 리뷰에서는 줄거리를 평가의 전제로 필요한 만큼만 요약한다. 평가마다 장면·문장·형식의 근거를 연결한다. | 작품을 보지 않아도 쓸 수 있는 형용사만 남았는가? Ebert 리뷰 분석에서 도출. [R4][r4] |
| R-13 | 취향과 성취 판단을 나눈다. 선호하지 않는 형식도 작품의 시도 안에서 어떤 효과를 내는지 검토한다. | ‘지루했다’가 무엇의 효과인지 설명했는가? 작품 리뷰 사례에서 재구성. [R4][r4] |
| R-14 | 끝에서는 사용자별 선택과 불확실성을 함께 적는다. 버전·가격·조건이 바뀌면 결론도 재검토한다. | 추천이 유지되는 조건과 뒤집히는 조건은 무엇인가? [R1][r1] |

### 비교 기준 수립 절차

다음은 메모 앱 비교를 위한 **가상 설계 예시**다. 실제 제품의 기능·가격·성능을 조사한 결과가 아니다.

| 단계 | 실행 |
|---|---|
| 1. 결정 정의 | “인터넷이 불안정한 현장에서 혼자 기록할 앱을 고른다” |
| 2. 필수 조건 | 오프라인 작성·저장, 데이터 내보내기 여부를 확인한다 |
| 3. 평가 기준 | 입력 편의, 검색, 백업·이동, 총비용을 정한다 |
| 4. 관찰 단위 | 메모 생성, 파일 첨부, 오프라인 수정, 재접속, 내보내기를 같은 자료로 수행한다 |
| 5. 증거 기록 | 버전·기기·시험일·설정·결과·오류를 남긴다 |
| 6. 해석 | 어느 차이가 현장 사용의 손실이나 이익이 되는지 설명한다 |
| 7. 결론 | 필수 조건 충족 여부를 먼저 판단하고 나머지 차이를 비교한다 |

점수를 쓴다면 ‘좋음 5점’처럼 막연하게 정하지 않는다. 예를 들어 내보내기는 ‘지원 안 함 / 일부 자료만 가능 / 필요한 자료와 구조를 보존’처럼 관찰 가능한 구간을 만든다. 가중치를 바꾸었을 때 순위가 쉽게 뒤집히면 ‘종합 1위’보다 우선순위별 추천을 제시한다.

협찬·제품 제공·제휴 관계가 있다면 평가 자료와 함께 기록해 독자가 판단에 필요한 관계를 알 수 있게 한다. 이는 검토 범위를 밝히는 운영 규칙이다.

### 흔한 실패와 신호

| 실패 | 초안에서 보이는 신호 | 수정 방법 |
|---|---|---|
| 사양표를 리뷰로 포장 | 기능 소개 뒤에 ‘추천한다’만 붙는다 | 실제 사용 결과·장면·조건을 확보한다 |
| 비교 기준의 이동 | A는 가격, B는 디자인으로 칭찬한다 | 같은 기준표를 먼저 채운다 |
| 허위 체험 | 자료에 없는 “며칠 써보니”가 등장한다 | 직접 체험과 문서 조사를 분리한다 |
| 가짜 정밀성 | 근거 없이 8.7점·9.2점을 준다 | 점수 구간을 정의하거나 서술 평가로 바꾼다 |
| 형식적인 단점 | 중요한 제약 대신 포장·색상만 지적한다 | 실제 선택을 바꿀 손실을 검토한다 |
| 모두에게 추천 | 어떤 조건에도 적합하다고 한다 | 비추천 조건과 대안을 쓴다 |
| 줄거리로 채운 작품 리뷰 | 요약 뒤에 “감동적·몰입감 있다”만 있다 | 장면의 형식과 효과를 분석한다 |
| 승자를 위한 후보 선택 | 경쟁력 없는 대안만 비교한다 | 같은 독자의 문제를 해결하는 후보를 재선정한다 |

### 좋은 예시 글과 읽는 이유

| 글 | 관찰할 지점 |
|---|---|
| RTINGS, 「Sony WH-1000XM5 Wireless Review」 | 용도별 판단, 장단점, 시험 항목, 경쟁 제품 비교를 연결한다. 하나의 총평으로 모든 사용 상황을 덮지 않는 방식을 읽는다. 이 글은 글쓰기 사례이며 현재 구매 추천이 아니다. [R3][r3] |
| Roger Ebert, 「Spirited Away」의 Great Movies 리뷰 | 구체적 장면과 움직임의 여백을 통해 작품의 미학적 효과를 설명한다. ‘아름답다’는 평가를 어떤 관찰로 뒷받침하는지 읽는다. 본문 직접 열람은 실패했으며 검색 색인에서 해당 대목만 확인했다. [R4][r4] |

## 뼈대 선택 기준

한 대상의 적합성 평가는 A, 후보 선택은 B, 작품의 형식과 효과 평가는 C를 고른다.

## 출처와 확인 범위

2026-11-15 조사 기록이다. 본문 확인·일부 확인·확인 못 함을 아래 범위대로 구분한다. 책 전체를 확인했다는 뜻이 아니다.

- **R1. Google Search Central, 「How to write reviews」.**  
  사용자 관점·경험 증거·측정·비교·장단점·중요한 결정 요인·추천 근거 지침 확인.  
  [공식 지침][r1]

- **R2. University of North Carolina Writing Center, 「Comparing and Contrasting」.**  
  비교 목적, 기준 선택, 공통 항목 정리와 구성 방식 확인.  
  [원문][r2]

- **R3. RTINGS, 「Sony WH-1000XM5 Wireless Review」.**  
  용도별 평가·시험 항목·장단점·경쟁 제품 비교 본문 확인. 측정 자체를 독립 재현한 것은 아님.  
  [리뷰 원문][r3]

- **R4. Roger Ebert, 「Spirited Away」, Great Movies 리뷰.**  
  검색 색인에서 구체적 장면과 움직임의 여백에 관한 분석 확인. 사이트 본문 직접 열람은 403 오류로 실패. 전체 글의 구조·최종 결론은 확인 못 함.  
  [리뷰 페이지][r4]

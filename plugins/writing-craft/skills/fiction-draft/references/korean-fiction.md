# 한국어 소설 표기와 말투 카드

출처의 설명을 작업 규칙으로 재구성한 작법 도구다. 구조·비율은 검증된 표준이 아니며 실패 신호는 AI 판별 근거가 아니다.

## 한국어 소설에서 별도로 관리할 문제

다음은 한국어에서 특히 별도 명세가 필요한 항목이다. 따옴표는 국립국어원 규범에 근거한다. 나머지는 작품별 편집 운영안이며, 문학적 의도를 없애는 교정 규칙으로 쓰지 않는다. [S31]

| 문제 | 스킬 지시문 | 점검 방식 |
|---|---|---|
| 호칭과 관계 | `화자→청자` 방향별 호칭을 기록한다. 직장·사적 자리·분노 상황의 차이도 둔다. | 같은 관계에서 호칭이 바뀐 문장을 추출해 이유 확인 |
| 높임 단계 | 인물 전체에 존댓말 하나를 붙이지 말고 상대별 해요체·하십시오체·반말 등을 정한다. 변화는 사건으로 취급한다. | 어미 변화 후보 탐지 후 관계·상황 대조 |
| 주체 높임 | 청자 높임과 주체 높임을 구분한다. 누구를 높이는 ‘-시-’인지 확인한다. | 높임 대상과 서술어의 대응 검토 |
| 시제와 회고 | 기본 서술 시점과 회상·현재적 논평을 구분한다. 과거완료 표현을 기계적으로 늘리지 않는다. | 시간선과 시제 전환 위치 대조 |
| 문장 끝 반복 | 같은 종결 형태가 연속되면 낭독한다. 단순히 ‘-다’를 피하려고 ‘-것이었다’를 늘리지 않는다. | 동일 종결 반복은 경고만 하고 자동 교체 금지 |
| 주어 생략 | 인물이 여럿 행동하거나 화자가 바뀔 때 지시 대상을 복원한다. 매문장 이름을 넣지는 않는다. | 행동 주체가 둘 이상 해석되는 구간 확인 |
| 대명사·이름 | ‘그/그녀’와 이름의 반복을 대조한다. 성별 대명사로 해결한 지시가 한국어에서 더 모호해지지 않는지 본다. | 연속 대명사·이름 빈도는 후보 탐지 |
| 직접 대사 | 기본값은 큰따옴표다. 인용 안의 인용과 마음속 말은 작은따옴표의 용법을 따른다. | 부호 짝·중첩 자동 검사 |
| 내면 서술 | 작은따옴표 독백과 자유간접화법을 구별한다. 인물의 생각을 모두 따옴표로 감싸지 않는다. | 화법 명세와 대조 |
| 대사 문단 | 기본값은 발화자가 바뀌면 문단을 바꾸는 편집 관례로 정한다. 출판사·작품 규약이 있으면 따른다. | 문단별 화자 후보 검토 |
| 말줄임·시스템창 | 말줄임표, 괄호, 상태창 표기를 작품 안에서 통일한다. 침묵과 단순한 문장 미완성을 구분한다. | 문자·패턴 자동 검사 |
| 사투리·고어 | 표면 어미만 덧붙이지 말고 어휘·구문·관계 규범을 함께 조사한다. | 별도 조사 근거와 독자 검토 필요 |

**말투 카드 예시**

```text
인물 A → 상사: 해요체, 결론을 늦추고 조건부터 말함
인물 A → 동료: 짧은 평서문, 부탁을 질문으로 위장함
인물 A → 가족: 주어 생략이 많고 전문 어휘를 피함
압박 시 변화: 말이 짧아지며 이름 대신 직함을 부름
금지: 모든 상대에게 같은 농담·같은 높임 사용
```

문장 끝 반복이나 사투리 빈도는 문체의 표면값이다. 수치가 높다는 이유만으로 감점하지 말고, 읽기 효과와 인물 구별에 미치는 영향을 판정한다.

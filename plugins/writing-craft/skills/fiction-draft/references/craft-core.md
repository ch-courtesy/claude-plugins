# 소설 공통 작법

출처의 설명을 작업 규칙으로 재구성한 작법 도구다. 구조·비율은 검증된 표준이 아니며 실패 신호는 AI 판별 근거가 아니다.

## 공통 설계: 인물·구조·시점·장면

### 인물표와 선택의 조건

작성 전에 정할 주인공의 최소 인물표는 다음과 같다. 욕망과 내적 장애를 구분하는 방식은 Robin Perini·Laura Baker의 작가 워크숍 자료에 근거한다. 아래 필드 구성은 이를 확장한 작업용 필드다. [S05]

```text
인물 ID / 이름 / 역할:
외적 욕망: 이번 이야기에서 얻거나 막으려는 구체적 결과
실패 비용: 잃는 것, 다치는 관계, 지나가는 기회
내적 장애: 욕망을 추구하는 방식을 왜곡하는 믿음·두려움·습관
현재 전략: 그 장애 때문에 반복하는 행동
경계선: 지금은 하지 않겠다고 생각하는 일
모순: 말하는 가치와 실제 선택이 다른 지점
관계별 태도: 누구에게 무엇을 숨기고 무엇을 요구하는가
변화 경로: 변화 / 타락 / 신념 유지 중 선택
말투: 어휘·문장 길이·생략·높임·비유·회피 방식
```

**결핍을 과거의 상처와 동일시하지 않는다.** 상처가 있어도 현재의 선택을 바꾸지 않는다면 인물 설계에 필요한 정보가 아닐 수 있다. “버림받았다”보다 “거절을 피하려고 먼저 관계를 끊는다”가 장면으로 옮기기 쉽다.

변화 곡선은 다음처럼 작성한다.

> 초기 전략 → 그 전략의 부분적 성공 → 커지는 부작용 → 대안과의 충돌 → 비용을 치르는 최종 선택

성장만 허용하지 않는다. 끝까지 신념을 유지하면서 주변을 바꾸는 인물, 더 나쁜 선택으로 자신을 파괴하는 인물도 가능하다. 스킬은 선택한 곡선과 실제 결말이 맞는지 검사해야 한다.

### 주 구조 하나의 선택

| 도구 | 구조 템플릿 | 적합한 용도와 점검 질문 |
|---|---|---|
| 3막 | 기존 질서·발단·진입 → 시도·대가·위기 → 최종 선택·결과 | 목표 지향 서사의 큰 인과를 설계한다. “2막의 실패가 마지막 선택을 필요하게 만드는가?” |
| Save the Cat | 시작 이미지·주제 제시·설정·촉발·망설임 → 2막 진입·B스토리·전제의 재미·중간점·압박·상실·침잠 → 3막 진입·결전·마지막 이미지 | 변화 중심 대중서사의 누락을 찾는다. 비트를 장면 수와 동일시하지 않는다. |
| 기승전결 | 상황과 관점 제시 → 관계·규칙 축적 → 앞선 내용을 바꾸는 전환 → 달라진 의미의 정착 | 인식·관계·이미지 중심 작품에 쓸 수 있는 작업용 틀이다. ‘전’을 반드시 충격 반전으로 만들지 않는다. |
| Scene/Sequel | 목표·충돌·불리한 결과 → 반응·검토·결정 → 새 목표 | 인접한 사건 사이의 인과와 감정 연결을 점검한다. |

Save the Cat의 15비트와 대략적 위치는 Jessica Brody의 공식 스타터 키트에서 확인된다. 소설판에서는 촉발 약 10%, 2막 진입 약 20%, 중간점 50%, 상실 약 75%, 3막 진입 약 80%를 제시한다. **이 수치는 해당 방법론의 권장 위치이며, 모든 소설의 합격 기준이 아니다.** [S02]

위 표의 기승전결 적용은 초안 작성용 설계안이다. 이를 3막과 일대일 대응시키거나, 특정 한국 웹소설 플랫폼의 공식 작법이라고 뒷받침하는 1차 자료는 **확인 못 함**.

### Swain과 Bickham의 Scene/Sequel

Dwight V. Swain의 《Techniques of the Selling Writer》는 장면과 여파를 연결하는 대표적인 작법서다. 출판사 자료에서 책의 범위와 서지를 확인했으며, 구체 도식은 Swain·Bickham을 참조하는 작가 워크숍 자료로 교차 확인했다. [S03][S05]

- **Swain의 Scene:** 목표 → 충돌 → 재난·좌절.
- **Swain의 Sequel:** 반응 → 딜레마 → 결정.
- **Bickham의 Sequel:** 감정 → 사고 → 결정 → 행동. 《Scene & Structure》 7장의 구성이다. 다음 행동으로 이어지는 연결을 더 명시한다. [S04]

여기서 재난은 반드시 죽음이나 대폭발이 아니다. “허가를 받았지만 동행자가 붙었다”처럼 성공에 비용이 붙는 결과도 활용할 수 있다.

장면 작성 규칙은 다음과 같다.

> 장면을 쓰기 전 시점 인물의 당면 목표를 적어라. 결과가 나오면 그 결과가 다음 목표를 어떻게 바꾸는지 확인하라. 반응과 판단이 독자에게 자명하면 압축하고, 선택의 비용을 이해하는 데 필요하면 여파를 확장하라.

모든 장면에 여섯 단계를 같은 길이로 출력하지 않는다. Bickham도 속도에 따라 구성 요소의 생략·확장·변형을 다룬다. 서정적·실험적 소설 전체를 이 도식으로 분류할 필요도 없다. [S04]

### 시점·화자·서술 거리

다음 네 질문은 서로 다르다.

1. **누가 말하는가?** 사건 속 인물, 회고하는 인물, 외부 화자.
2. **누구의 지각을 통과하는가?** 한 인물, 여러 인물, 외부 관찰.
3. **무엇까지 아는가?** 당시 지식, 회고 후 지식, 타인의 내면.
4. **얼마나 가까이 붙는가?** 역사적 요약, 외부 행동, 감각, 즉각적인 내적 언어.

John Gardner의 ‘심리적 거리’는 네 번째 문제를 다루는 데 유용하다. Stanford 교육 자료는 이를 독자가 사건에서 느끼는 거리로 설명하고, 문체의 확대·축소 도구로 가르친다. [S07]

```text
장면 시점:
화자의 발화 시점:
접근 가능한 내면:
접근할 수 없는 정보:
서술 거리:
시점 전환 표지:
```

제한적 3인칭 장면에서 다른 인물의 의도를 사실처럼 쓰면 경고한다. 다만 전지적 화자를 선택한 작품까지 ‘시점 위반’으로 판정해서는 안 된다. Le Guin 역시 제한적 시점만을 좋은 서술로 취급하는 관행을 비판한다. [S10]

### 대사의 표면 내용과 실제 목적

McKee는 서브텍스트를 장면 속 욕망과 그것을 얻기 위한 행동에서 설명한다. 인물이 실제로 원하는 것, 상대의 저항, 이를 돌파하는 전략을 먼저 정하라는 뜻이다. [S06]

| 항목 | 작성 질문 |
|---|---|
| 표면 내용 | 지금 무슨 이야기를 하는가? |
| 실제 목적 | 허락·인정·정보·거리·주도권 중 무엇을 얻으려는가? |
| 숨기는 것 | 왜 직접 요구하지 못하는가? |
| 전술 | 농담·회피·거래·위협·침묵 중 무엇을 쓰는가? |
| 변화 | 상대의 반응 때문에 전술이 바뀌는가? |

예를 들어 “우린 이제 서로를 믿어야 해”라는 설명을 썼다면, 실제 목적이 신뢰인지 공범 만들기인지 먼저 정한다. 후자라면 “네 이름도 적었어”처럼 행동과 대사가 함께 작동할 수 있다. 이 예문은 작법 설명용 가상 예시다.

인물별 말투는 유행어 한 개로 구분하지 않는다. 문장 길이, 대답의 직접성, 전문 어휘, 상대에 따른 높임, 감정을 피하는 방법을 다르게 한다. Writing Excuses는 대화 장면에 물리적 목표와 대화상의 목표를 함께 주고, 리듬·구문·어휘·태도로 목소리를 구별하도록 제안한다. [S12]

### 보여 주기·말하기·페이싱

Le Guin은 ‘보여 주고 말하지 말라’를 절대 법칙으로 만드는 데 반대한다. 설명·화자의 목소리·과거 시제도 서사의 자원이다. [S10]

| 내용의 역할 | 기본 처리 |
|---|---|
| 결정적 선택, 관계가 바뀌는 순간 | 행동·대사·감각을 가진 장면으로 검토 |
| 반복되는 일상, 이동, 이미 이해한 절차 | 요약·생략으로 검토 |
| 세계의 규칙 | 현재 행동에 필요한 만큼 설명 |
| 사건 뒤 감정·판단 | 다음 선택을 이해하는 데 필요한 길이로 |
| 화자 자체가 주는 즐거움 | 목소리와 리듬의 기능을 살려 유지 |

“요약이라서 삭제”, “감정을 직접 말했으므로 감점” 같은 규칙은 넣지 않는다. **같은 내용을 장면과 설명으로 중복 전달하는지**, 설명이 필요한 경험을 대신하고 있는지를 검사한다.

페이싱은 사건 수보다 **약속한 종류의 진전이 느껴지는가**로 본다. 수수께끼를 약속한 작품에서 전투만 늘려도 독자는 정체를 느낄 수 있다. Sanderson과 Writing Excuses의 약속·진전·보상 논의가 이 구분에 유용하다. [S11][S13]

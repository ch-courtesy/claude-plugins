# 채점표 초안 — 리뷰·비교 글

> **상태: 초안.** 2026-11-15 비소설 장르 작법 조사 5.6절의 표를 옮겼다. 출처 설명을 작업 절차로 재구성한 것이지 검증된 척도가 아니다. 합격선은 정하지 않는다(실제 사용 뒤 보정). 기계 칸: 자동/가능 = 결정적 검사, 보조/부분 = 후보 탐지 뒤 판정, 사람/불가 = 의미 판단.

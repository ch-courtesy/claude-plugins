# 채점표 초안 — 수필(개인 에세이·성찰형 칼럼)

> **상태: 초안(W-429).** HQ `research/2026-11-15-writing-genres-nonfiction.md 2.5`의 표를 옮겼다. 출처 설명을 작업 절차로 재구성한 것이지 검증된 척도가 아니다. 합격선은 정하지 않는다(W-430 평가 뒤 보정). 기계 칸: 자동/가능 = 결정적 검사, 보조/부분 = 후보 탐지 뒤 판정, 사람/불가 = 의미 판단.

‘기계’는 규칙 기반 점검을 뜻한다. **가능**은 명시적 필드·형식 확인, **부분**은 후보 탐지, **불가**는 의미 판단이 필요하다는 뜻이다. LLM 평가도 자동화할 수 있지만, 여기서 ‘기계적으로 확인 가능’과 같은 의미로 취급하지 않는다.

| 항목 | 0점 | 1점 | 2점 | 기계 |
|---|---|---|---|---|
| 중심 질문 | 소재만 있다 | 질문이 여러 방향으로 흩어진다 | 경험을 관통하는 질문이 있다 | 불가 |
| 구체성 | 추상적 감정만 있다 | 구체적이나 대체 가능한 세부다 | 해석에 필요한 행동·말·사물이 있다 | 부분 |
| 성찰의 기여 | 감정을 반복한다 | 해석이 있으나 근거가 약하다 | 경험의 원인·모순·관계를 탐색한다 | 불가 |
| 사고의 움직임 | 처음 판단을 반복한다 | 변화는 선언한다 | 판단이 수정되거나 정교해지는 과정이 보인다 | 불가 |
| 자기 관찰 | 자신을 정당화한다 | 형식적 반성을 한다 | 자기 행동과 이해의 한계를 검토한다 | 불가 |
| 장면·성찰의 연결 | 서로 무관하다 | 일부만 연결된다 | 주요 해석이 경험에 닿아 있다 | 불가 |
| 타인 재현 | 속마음을 단정한다 | 관찰과 추정이 섞인다 | 관찰·전언·해석을 구분한다 | 부분 |
| 사실·기억 관리 | 자료 없는 체험을 확정한다 | 불확실성 일부를 표시한다 | 자료와 대조하고 불확실한 기억을 구분한다 | 부분 |
| 끝맺음 | 교훈을 덧붙이거나 중단된다 | 앞 내용을 정리한다 | 핵심 질문·이미지를 새 의미로 닫는다 | 불가 |
| 표현의 고유성 | 상투어가 경험을 대신한다 | 구체적 표현과 상투어가 섞인다 | 해당 경험에 맞는 언어가 유지된다 | 부분 |

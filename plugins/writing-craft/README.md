# writing-craft

수필·설명문·논설문·리뷰와 소설의 초안을 쓰고 진단하는 장르별 작법 플러그인이다. 현업 시니어 편집자·작가가 자기 이름으로 낼 수 있는 초안과 진단을 목표로 한다.

## 스킬과 사용 시점

| 스킬 | 사용 시점 | 결과 |
|---|---|---|
| `writing-craft:nonfiction-draft` | 수필·설명문·논설문·리뷰·비교 글 초안 | 자료에 근거한 초안과 작업 메모 |
| `writing-craft:fiction-draft` | 단편·장편·웹소설의 장면·회차 작성 | 본문과 분리한 장부 갱신안 |
| `writing-craft:genre-rubric` | 장르별 퇴고 진단·독립 채점 | 다른 회사 모델의 항목별 근거·점수·수정 행동 |
| `writing-craft:story-ledger` | 긴 이야기의 설정 관리·연재 전 점검·설정 변경 | TOML 장부와 기계·모델 점검 보고 |

비소설은 독자·중심 질문·사용 자료·매체 규칙·출력 경로를 주고 시작하라. 소설은 인물의 욕망·선택 비용·시점·세계 규칙을 더하라. 장편·웹소설에는 장부 경로가 필요하다. 초안 뒤 독립 점검이 필요하면 `genre-rubric`을 부르라.

## 설치

이 저장소를 Claude Code 마켓플레이스로 등록한 뒤 다음 명령으로 설치하라.

```text
/plugin marketplace add <이 저장소의 URL 또는 로컬 경로>
/plugin install writing-craft@courtesy-claude-plugins
```

독립 채점에는 같은 마켓플레이스의 `recipe` 플러그인(`recipe:oneshot`)과 글쓴 모델과 다른 회사의 CLI 모델이 필요하다. 기계 점검에는 Python이 필요하며 장부 TOML 읽기는 Python 3.11 이상을 사용한다.

## blog-craft와의 관계

writing-craft는 블로그 밖에서도 쓰는 장르별 작법의 기반이다. blog-craft는 블로그 글의 주제 관문·첨부 시험·교차 리뷰·발행 전 채점을 잇는 공정이다. 이번 버전은 blog-craft를 수정하거나 자동 연결하지 않는다. 연결은 별도 작업이다. 블로그에서 규칙이 겹치면 blog-craft의 매체 규칙을 우선한다.

## 근거 자료와 한계

2026-11-15에 한 장르 작법 조사 두 건(비소설 출처 34개, 소설 출처 35개)을 바탕으로 구성했다. 작가의 공개 글·인터뷰·작품, 대학 글쓰기 자료, 공식 규범·플랫폼 공지를 각 reference의 출처와 확인 범위에서 추적할 수 있다. 영어 작법서 내용은 요약이며 책 전체를 확인한 것으로 주장하지 않는다.

구조 공식·분량 비율·채점표는 출처를 작업 절차로 재구성한 도구이며 검증된 표준이 아니다. 장르별 10항목을 0·1·2점으로 채점하되 적용 불가는 분모에서 빼고 합격선은 두지 않는다. 존재하지 않는 출처·지어낸 경험·중대한 설정 충돌 등은 총점과 별도로 먼저 고친다.

‘AI 초안의 실패 신호’는 편집 가설이며 AI 작성 여부 판별 기준이 아니다. 자료 공백은 작업 표시로 남긴다. 장부 기계 검사도 본문의 의미적 무모순을 보장하지 않는다.

플랫폼 정책 표는 **2026-11-15 당시 확인 기록**이다. 일반 연재·공모전·본문·이미지의 범위를 구분하며 확인 못 한 정책을 허용으로 판정하지 않는다. 실제 투고 전 최신 원문을 다시 확인하라.

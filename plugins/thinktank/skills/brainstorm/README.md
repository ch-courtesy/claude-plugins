# brainstorm

새로운 아이디어·대안·기회 영역을 폭넓게 탐색해 추적 가능한 **복수 후보군**과 검증 계획을 만드는 스킬. 메인 세션이 세션 책임자로 남아 프레이밍 인터뷰·중앙 리서치·발산·수렴·검증 승인을 관리한다.

- **무엇** — 발산·변환·군집·수렴을 거쳐 세션당 단일 파일 `.brainstorm/<session-id>.md`에 아이디어 계보·후보군·검증 계획을 섹션 단위로 누적한다. 이미 정해진 대안의 판정·이해관계 합의가 목표면 `roundtable` 스킬을 대신 쓴다.
- **언제** — 사용자가 브레인스토밍, 아이디어 발산, 콘셉트 탐색, 대안 생성, 아이디어 검증, 세션 재개·상태 확인을 요청할 때 활성화된다.
- **호출** — `Skill(skill="thinktank:brainstorm", args="<subcommand> [<args>]")`. 서브커맨드는 `start`(새 세션)·`resume`(재개)·`status`(읽기 전용 보고).

동작 명세의 단일 진실 출처는 [`SKILL.md`](./SKILL.md)와 [`references/`](./references/)이며, 이 문서는 그 계약을 복제하지 않고 가리킨다.

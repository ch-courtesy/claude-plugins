# 리서치 프로토콜

리서치는 아이디어를 대신 생성하거나 초기에 가능성을 제거하지 않는다. 세션 책임자가 질문을 통합해 **중앙 리서치**로 수행하며, 조사는 아래 두 단계로 나뉜다.

## 1단계: 발산 전 최소 리서치

프레임 승인 후 발산 전에 다음만 조사해 세션 파일의 연구 컨텍스트 섹션에 기록한다.

- 반드시 알아야 할 용어와 현재 상태
- 확정된 제약, 안전·법적 금지선
- 기존 시도와 명백한 중복을 알아보는 최소 배경
- 아이디어 생성에 유용한 유사 사례나 자산

상세 시장 분석, 완전한 경쟁사 목록, 후보별 타당성 판정은 하지 않는다. 조사량은 발산을 시작할 수 있는 최소 수준으로 제한한다.

## 2단계: shortlist 이후 상세 검증

후보 목록(shortlist)이 만들어진 뒤에만 후보별 핵심 가정을 조사한다.

- 가장 위험하고 결과를 바꿀 가정부터 검증한다.
- 후보별 동일 질문은 공동 조사로 묶는다.
- 상충 출처와 최신성 의존 정보를 표시한다.
- 후보 채택·탈락을 좌우하는 핵심 사실은 서로 독립인 출처 2개 이상으로 확인하고, 하나뿐이면 추정으로 표시한다. 반증 증거도 함께 찾아 기록한다.
- 리서치만으로 판단할 수 없는 가정은 검증 계획 섹션의 실험 후보로 넘긴다.

검증 리서치는 승인된 계획의 질문에만 답하며 새로운 외부 실행을 시작하지 않는다.

# 전략 프로토콜

## 선택 규칙

- **Brainwriting은 항상** 첫 발산 전략으로 사용한다.
- 아이디어 다양성이 정체되거나 기존 제품·프로세스의 개선형 주제이면 **SCAMPER**를 추가한다.
- 군집화 후 의뢰자 가치에 맞는 복수 후보로 **수렴할 때 NGT**를 사용한다.

## Brainwriting: 독립 발산

1. 서로 다른 렌즈의 생성자 3–6명에게 동일한 프레임과 각자 관련 정보만 전달한다.
2. 각 생성자는 다른 생성자의 결과를 보지 않고 독립적으로 아이디어를 생성한다.
3. 세션 책임자는 아이디어를 아이디어 풀 섹션에 그대로 추가하고 중복 후보만 표시한다.
4. 발산 중 비판, 평가, 순위, 합의를 금지한다. 실행 가능성 부족도 삭제 사유가 아니다.

각 아이디어는 `idea-id`, `strategy: Brainwriting`, 작성 렌즈, 설명, 기대 가치, 새로움, 전제 가정을 포함한다.

## 다양성 점검과 SCAMPER

다음 중 하나면 다양성 정체로 판단한다.

- 최근 라운드의 대부분이 기존 군집에만 추가된다.
- 표현은 다르지만 작동 원리가 반복된다.
- 렌즈별 결과가 같은 해결책 유형으로 수렴한다.

정체 시 Substitute, Combine, Adapt, Modify, Put to another use, Eliminate, Reverse 렌즈를 필요한 만큼 적용한다. 변환 아이디어는 새 `idea-id`, `strategy: SCAMPER`, 원본의 `parent-id`를 기록한다.

## 군집화

- 해결책 이름보다 해결 원리와 만들어내는 가치로 군집화한다.
- 한 아이디어가 여러 군집에 관련되면 교차 참조한다.
- 군집 밖의 고유 아이디어를 강제로 합치지 않는다.
- 군집 섹션에는 군집 설명, 포함 idea-id, 공통 가정, 차별점, 미해결 질문을 기록한다.

## NGT 수렴

1. 의뢰자 가치 기반 평가 기준과 가중치를 먼저 확인한다.
2. 생성자 또는 별도 평가자가 각 후보를 독립적으로 평가하고 근거를 쓴다.
3. 점수 차이와 반대 근거를 토론하되 단순 평균으로 숨기지 않는다.
4. 서로 다른 가치 제안과 위험 프로필을 가진 후보군을 선택한다.
5. 단일 우승자를 강제하지 않고 핵심 가정과 검증 우선순위를 기록한다.

평가 결과에는 가치 적합성, 차별성, 학습 가치, 주요 위험, 증거 수준, 다음 검증을 포함한다.

# 역할 프롬프트

세션 책임자는 주제 복잡도와 필요한 관점 차이에 따라 아이디어 생성자 **3–6명**을 적응형으로 선택한다. 이름만 다른 중복 렌즈는 제거한다.

생성자·평가·검증 역할의 모든 Agent brief에는 "메인 세션 컨텍스트는 보이지 않는다(이 brief가 전부다). 중첩 Agent를 호출하지 않는다."를 명시한다.

## 세션 책임자

메인 세션이 맡는다. 아이디어 생성에 직접 개입해 특정 결론으로 유도하지 않고, 발산과 수렴의 규칙 위반을 차단하며, 최종 보고서가 원본 아이디어·반대 근거·불확실성을 정확히 반영하는지 검토한다.

## 공통 생성자 brief

```markdown
역할: [탐색 렌즈]
프레임: [how-might-we와 범위]
보호할 가치: [이 렌즈가 놓치지 않을 가치]
관련 정보: [전체 자료가 아닌 관련 최소 컨텍스트]
전제: 메인 세션 컨텍스트는 보이지 않는다. 이 brief가 전부다.
과업: 다른 생성자의 결과를 보지 않고 독립적으로 아이디어 생성
금지: 발산 중 비판·평가·순위·합의, 프레임 밖 실행, 중첩 Agent 호출
출력: idea-id 후보, 아이디어, 기대 가치, 새로움, 핵심 가정
```

## 아이디어 생성자 렌즈

| 렌즈 | 초점 | 금지 편향 |
|---|---|---|
| 사용자·고객 탐색자 | 미충족 욕구, 여정, 접근성 | 요청된 기능만 반복 |
| 도메인 유추자 | 다른 산업·자연·역사 사례의 작동 원리 | 표면적 복제 |
| 제약 전환자 | 제약을 차별화 요소나 설계 재료로 전환 | 제약 무시 |
| 시스템 사고자 | 행위자, 인센티브, 피드백 루프 | 단일 접점 최적화 |
| 급진적 탐색자 | 가정 뒤집기, 비연속 대안 | 충격만 노린 아이디어 |
| 실용적 조합자 | 기존 자산의 새로운 결합과 단계적 접근 | 익숙한 해법만 반복 |

## 평가·검증 역할

### NGT 평가자

각 후보를 의뢰자 가치 기준으로 독립 평가한다. 점수, 근거, 불확실성, 반대 근거, 검증 우선순위를 함께 쓴다.

### 에이전트 비판자

승인된 후보의 핵심 가정과 실패 경로를 공격적으로 검토하되 아이디어를 임의 삭제하거나 범위 밖 실행을 제안하지 않는다.

### 검증 설계자

최소 비용으로 가장 중요한 불확실성을 줄이는 상세 리서치, 에이전트 비판, 단순 문서, 목업, 프로토타입 실험을 설계한다. 모든 산출물은 `.forum/**` 안에 두고 코드베이스·외부 시스템을 변경하지 않는다.

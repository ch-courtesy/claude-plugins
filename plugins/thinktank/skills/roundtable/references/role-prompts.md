# 운영 역할 Agent brief

모든 brief에 회의 ID, 승인된 아젠다, 허용 정보 범위, 기대 응답 형식을 포함한다. Agent는 메인 컨텍스트를 보지 못하며 중첩 Agent 호출을 하지 않는다고 명시한다.

## 회의 책임자

메인 세션이 맡는다. 의뢰자 인터뷰, 승인 게이트, 중앙 리서치, 참여자 선정, Agent 디스패치, 상태 저장, 최종 검토를 책임진다. 결론을 미리 정하거나 기록자의 문서를 임의 수정하지 않는다.

## 중앙 리서처

**임무:** 회의 책임자가 승인된 아젠다에서 작성한 `research-plan.md`를 한 번 실행해 공통 증거 팩을 작성한다.

**금지:** 참여자 역할 수행, 최종 대안 선택, 출처 없는 주장을 사실로 표시, 중첩 Agent 호출.

**응답:** `evidence-pack.md` 템플릿을 채울 수 있는 완결된 Markdown과 계획에서 해결하지 못한 정보 공백.

## 리서치 검증자

**임무:** 증거 팩의 출처 품질, 최신성, 상충 정보, 과장, 누락을 독립 검토한다.

**금지:** 결론 선택, 새로운 회의 범위 추가, 근거 없는 반박.

**응답:** Critical·Important·Minor 발견, 영향을 받는 증거 ID, 필요한 수정 또는 추가 조사.

## 진행자

**임무:** 중립적으로 결정 지도를 만들고, 다음 질문·발언 대상·추가 조사·조기 종료·합의 판정을 결정한다.

**금지:** 고유 입장 제시, 참여자 직접 호출, 중첩 Agent 호출, 조건부 합의를 완전 합의로 변경.

**응답:**

```text
라운드 판정:
합의된 항목:
남은 핵심 쟁점:
다음 질문과 대상 역할:
통합된 추가 조사 요청:
합의 기준 상태:
조기 종료 여부와 근거:
```

## 기록자

**임무:** 아젠다, 증거 ID, 결정 지도, 라운드 판정을 바탕으로 구조화 기록과 최종 문서를 작성한다.

**금지:** 전체 발화 재작성, 새 결론 추가, 반대 의견 삭제, 합의되지 않은 내용을 합의로 기록.

**응답:** 요청받은 `discussion.md`, `agreement.md`, `no-consensus.md` 템플릿의 완결된 Markdown.

# Codex 상호작용 규칙

사용자에게 결정·승인·선택·해명을 요청할 때는 `request_user_input`을 사용합니다. 자유 텍스트 끝에 질문을 붙이지 않습니다.

## 발신 전 점검

마지막 문단에 아래 신호가 있으면 질문 부분을 `request_user_input`으로 분리합니다.

- `?`, `Y/N`, `A vs B`
- "...할까요", "...할지", "...주세요", "알려주세요", "결정해주세요", "선택해주세요", "어떻게 할까요", "괜찮을까요"
- "원하시면 ...", "필요하시면 ...", "괜찮으시면 ..."처럼 실제로는 결정을 요청하는 표현

## 트리거 (이 중 하나라도 해당되면 도구 사용)

- 두 개 이상의 선택지·옵션 제시
- 결정·승인·선호 요청
- 모호한 요구의 의도 확인
- 보고·요약·완료 발표 뒤 다음 단계를 묻는 경우

한 턴에 여러 결정 질문이 있으면 한 번에 최대 4문항까지 묶습니다.

## 예외 (도구 불필요)

- 순수 단방향 보고: 결과·진행 상황만 알리고 결정·승인·다음 단계 요청이 없을 때.
- 사용자가 자유 서술 답변을 명시적으로 원하는 경우 ("네 생각을 자세히 풀어 줘", "에세이로 답해 줘").

보고와 결정 요청이 섞이면 보고는 자유 텍스트로, 결정은 `request_user_input`으로 분리합니다.

# 입력(inputs) 치환 규칙 (단일 출처)

SKILL.md 생성 절차의 "입력 치환" 스텝이 가리키는 상세 규칙. 산출 대상 템플릿 frontmatter에 `inputs`가 있으면 처리하고, 없으면 건너뛴다. 한 입력은 `multi_select` 값에 따라 **다중 선택(집계)** 또는 **단일 선택** 두 모드 중 하나로 동작한다. (현재 `git` 템플릿이 multi-select를, `review-approval` 템플릿의 `merge_method`가 single-select를 쓴다.) 집계·연결은 `references/template_tools.py aggregate ...`로 고정한다.

## 스키마

각 입력은 `name`, `header`, `question`, `multi_select`, `options[{label, description, value?, default?}]`를 가진다. `multi_select: true`는 **한 질문에서 여러 정책을 다중 선택**함을, `multi_select: false`(또는 생략)는 **한 질문에서 정확히 하나를 고르는 단일 선택**을 뜻한다.

## 질문

입력을 현재 런타임의 구조화된 사용자 질문 기능으로 **한 번** 묻되, 다중 선택 입력은 **multi-select**로, 단일 선택 입력은 **single-select**로 제시한다. 옵션 표시 순서는 frontmatter 순서를 따른다. `default: true`인 옵션은 **기본 선택(체크)** 상태로 제시한다(추천·기본 옵션을 첫 번째에 둔다). 사용자에게는 정책·방식 선택지만 노출하고, 정책이 공통으로 분리된 내부 사정·분류 기준은 노출하지 않는다.

## 옵션 1개뿐인 다중 선택 폴백

다중 선택 입력의 제시 가능한 옵션이 정확히 1개뿐이면, 옵션 1개짜리 다중 선택을 현재 런타임의 구조화된 사용자 질문 기능이 거부하므로(옵션 최소 2개 요구) 그 정책을 **허용/금지 single-select**로 제시한다 — '금지(적용)'를 고르면 그 옵션 값을 본문에 넣고(집계와 동일), '허용(미적용)'을 고르면 빈 값으로 처리해 절을 제거한다(예: `git.md`의 force push 금지 정책).

## 집계 치환 (다중 선택)

본문의 **단일 집계 placeholder** `{{<name>}}`를, **선택된 옵션들의 값을 표시 순서대로 연결**한 텍스트로 치환한다. 값은 `value`가 있으면 `value`, 없으면 `label`을 쓴다(value 우선). 비어 있지 않은 "Other" 자유 입력도 연결 대상에 포함한다. 절과 절 사이는 빈 줄 하나로 구분해 마크다운 서식을 유지한다. **정책별 개별 placeholder는 두지 않는다.**

## 단일 치환 (단일 선택)

본문의 placeholder `{{<name>}}`를 **선택된 한 옵션의 값**으로 치환한다(`value` 우선, 없으면 `label`). 연결은 일어나지 않는다.

## 빈 선택

(다중 선택에서) 아무 옵션도 선택되지 않으면 집계 결과는 빈 문자열이고, placeholder가 놓인 줄을 절 단위로 정리·제거해 빈 줄·깨진 마크다운을 남기지 않는다. 도입부(헤더 + git 계열 분류)는 그대로 남긴다.

## 누락 응답 (디폴트 경로)

응답이 누락되면 `default: true`인 옵션(들)이 선택된 것으로 간주한다. 다중 선택에서는 force push 금지(기본 체크)가 적용되어 금지 절이 포함된 `git.md`가 생성되고(force push 미체크 = 허용), 단일 선택에서는 기본 옵션 하나가 적용된다(예: `merge_method` 미응답 시 "저장소 설정을 따름" 절이 들어가 기존 수동 안내로 자연 degrade).

## 확장

새 정책·방식은 frontmatter `options`에 **옵션 항목만 추가**하면 된다 — SKILL.md 로직, 본문 placeholder, 질문 수는 바뀌지 않는다.

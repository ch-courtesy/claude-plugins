# create-skill

인터뷰 기반으로 새 스킬(SKILL.md)을 설계·작성하는 `project-init` 스킬 — 루브릭 30항목 품질 기준을 작성 단계에 내장해 BLOCKER·MAJOR 0을 목표로 SKILL.md·README.md를 완성한다.

- **언제** — 사용자가 새 스킬 작성·설계·제작·초안 생성을 요청할 때(정확한 트리거는 `SKILL.md` description).
- **호출** — 트리거 감지 시 자동 활성화. 별도 인자 없음.

절차·규칙은 [`SKILL.md`](./SKILL.md), 루브릭 30항목 기준은 [`../../shared/rubric/criteria.md`](../../shared/rubric/criteria.md), 구조 틀은 [`references/skill-template.md`](./references/skill-template.md) 참조 — 이 문서는 폴더 진입점용 요약이며 본문을 복제하지 않는다.

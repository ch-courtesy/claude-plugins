# bootstrap

새 프로젝트의 공통 `AGENTS.md`와 선택한 벤더 골격을 설치하는 `project-init` 오케스트레이터 스킬입니다.

## 무엇을

공통 지침(`AGENTS.md`)과 사용자가 고른 벤더 골격(Claude Code·Codex)을 누락분만 설치하고, `rules/` 카테고리 지침 생성은 형제 `*-rule-creator` 스킬에 위임합니다. 기존 파일은 덮어쓰지 않습니다.

## 언제

새 프로젝트 초기화·세팅·셋업·환경 구성 요청이 있거나, 공통 지침·벤더 골격이 누락된 프로젝트에서 활성화됩니다. 정확한 트리거 표현은 `SKILL.md`의 `description`이 단일 출처입니다.

## 어떻게 호출

에이전트가 위 트리거를 감지하면 자동 활성화됩니다. 별도 서브커맨드·인자는 없습니다.

## 진입점·포인터

- 동작 명세(진행 순서·규칙)의 단일 출처: [`SKILL.md`](./SKILL.md)
- 조립 베이스·벤더 골격·선택 자산의 단일 출처: `../../shared/bootstrap/`
- 위임 대상 카테고리 생성기: 부모 `skills/`의 `*-rule-creator/`
- 계약 테스트: [`tests/`](./tests/)

> 이 문서는 폴더 진입점용 요약입니다. 진행 순서·규칙 본문은 `SKILL.md`에만 두며 여기서 복제하지 않습니다.

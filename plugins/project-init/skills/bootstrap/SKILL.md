# bootstrap

공통 `AGENTS.md`, 사용자가 선택한 벤더 골격, 선택한 `rules/` 카테고리를 설치합니다.

## 진행 순서

1. **루트와 기존 파일 확인.** 프로젝트 루트에서 `AGENTS.md`, `CLAUDE.md`, `.claude/settings.json`, `.codex/config.toml`, `rules/` 존재 여부를 확인합니다. 기존 파일은 절대 덮어쓰지 않습니다.

2. **벤더 선택 질문.** 먼저 **현재 이 스킬을 실행 중인 벤더(하니스)** 를 스스로 판단합니다 — 실행 중인 에이전트(LLM)가 자기 런타임을 보고 어느 벤더인지 판단하며, 별도 환경변수 감지 로직은 쓰지 않습니다. 이 현재 실행 벤더는 **필수로 자동 포함**하고, 선택 해제할 수 있는 선택지로 제시하지 않습니다.
   - 현재 실행 벤더를 **제외한 나머지 벤더**들을 정확히 하나의 구조화된 사용자 질문 기능으로 묻고, 사용자가 그중 0개 이상을 추가로 선택하게 합니다. 각 나머지 벤더를 독립 선택지로 제시합니다.
     - **나머지 벤더가 2개 이상이면 `multiSelect` 질문**으로 제시해 0개 이상을 선택하게 합니다.
     - **나머지 벤더가 정확히 1개이면 그 벤더의 포함/제외 single-select 질문**으로 제시합니다 — 구조화된 질문 기능이 옵션 최소 2개를 요구하므로, 옵션이 1개뿐인 `multiSelect`는 도구에 보내지 않습니다(도구 거부 회피).
   - 사용자가 나머지 벤더를 아무것도 추가 선택하지 않으면, 현재 실행 벤더의 골격만 설치합니다.
   - 구조화된 질문 기능이 **도구 자체의 빈 응답(tool null/empty response)** 을 돌려주는 환경에서는 어떤 파일도 생성·변경하지 않고 같은 질문을 다시 제시합니다. 최대 **3회** 연속 도구 빈 응답이면 아무 파일도 생성·변경하지 않은 채 bootstrap을 중단합니다. (이 가드는 벤더 선택에 한합니다.) 사용자가 나머지 벤더를 0개 선택해 정상 제출한 경우는 도구 빈 응답이 아니므로 이 가드를 트리거하지 않습니다.

3. **공통 선택 블록 질문.** 루트에 `AGENTS.md`가 없어 새로 생성할 때만, 카파시 코딩 룰과 사용자 상호작용 규칙 두 블록의 포함 여부를 정확히 하나의 구조화된 사용자 질문 기능의 **multiSelect** 질문으로 묻습니다. 두 블록을 별개의 single-select 질문이나 4개 조합 single-select로 묻지 않습니다.
   - `카파시 룰 (권장)`
   - `사용자 상호작용 규칙 (권장)`
   - 두 선택지 모두 **기본 포함(권장)** 으로 제시합니다. multiSelect는 사전 체크 상태를 표현하는 스키마가 없으므로, 라벨에 "(권장)"을 붙이고 설명에서 기본 포함 의도를 명시합니다 — 도구가 실제로 항목을 미리 체크해 주지는 않습니다.
   - 사용자가 두 항목 모두 선택하지 않으면, 두 블록 어느 것도 생성물에 포함하지 않고 흐름을 정상 진행합니다(재질문하지 않습니다). "둘 다 미선택"은 정상 결과이지 무선택 중단 대상이 아닙니다.
   - 선택하지 않은 블록은 생성물에 포함하지 않습니다.
   - 루트에 `AGENTS.md`가 이미 있어 이번 흐름에서 새로 생성하지 않으면 이 질문을 하지 않습니다.

4. **공통 `AGENTS.md` 생성.** `AGENTS.md`가 없을 때만 `../../shared/bootstrap/`의 단일 출처를 조립해 생성합니다.
   - 베이스: `../../shared/bootstrap/AGENTS.md`
   - 선택 자산: `../../shared/bootstrap/assets/karpathy-rules.ko.md`, `../../shared/bootstrap/assets/interaction-rules.ko.md`
   - 순서: `[카파시 룰(선택 시)] → [사용자 상호작용 규칙(선택 시)] → [카테고리별 지침]`
   - 각 블록은 형제 H1으로 시작하며 네트워크 접근 없이 동봉 자산만 사용합니다.

5. **선택 벤더 골격 생성.** 선택한 벤더의 누락 파일만 `../../shared/bootstrap/vendors/`에서 복사합니다.
   - Claude Code: `CLAUDE.md`, `.claude/settings.json`
   - Codex: `.codex/config.toml`
   - 기존 설정 파일은 내용과 무관하게 보존합니다.
   - 기존 `CLAUDE.md`에 `@AGENTS.md`가 없으면, 기존 내용을 보존한 import 추가 diff를 보여주고 승인받은 경우에만 `@AGENTS.md`를 첫 줄에 추가하고 빈 줄 뒤에 기존 내용을 보존합니다. 거부하면 수정하지 않고 요약에 경고합니다.
   - 선택하지 않은 벤더의 기존 파일은 수정하거나 삭제하지 않습니다.

6. **카테고리 선택.** 부모 `skills/`에서 `*-rule-creator/`만 열거하되 **`review-rule-creator`는 후보에서 제외**하고 접미사를 제거합니다 — 리뷰 지침 생성은 bootstrap 자동 흐름이 아니라 `review-rule-creator`의 독립 진입점(자체 스킬 호출)으로만 수행합니다. 후보를 일반 메시지로 한 번 출력한 다음 구조화된 사용자 질문 기능으로 전체 생성, 일부 선택, 아무것도 생성하지 않음 중 하나를 받습니다. `일부 선택`이면 카테고리별로 `생성`/`건너뜀` single-select 질문을 반복해 원하는 카테고리만 수집합니다.

7. **생성기 호출과 요약.** 선택된 형제 생성기만 호출하고, 생성·보존·승인 거절로 생략된 파일을 구분해 요약합니다.

## 규칙

- 이 오케스트레이터가 직접 만드는 파일은 `AGENTS.md`와 선택한 벤더의 누락 골격뿐입니다. `rules/<category>.md`는 각 생성기가 책임집니다.
- 공통 지침과 생성 자산의 단일 출처는 `../../shared/bootstrap/`입니다.
- 벤더 골격에는 Hook·모델·권한·MCP 기본값을 넣지 않습니다.
- `git init`, 의존성 설치, 패키지 매니저 실행을 하지 않습니다.

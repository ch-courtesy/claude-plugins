# 카테고리별 지침

`rules/` 디렉토리에 카테고리별 지침 파일이 있습니다. 세션 시작 시 주입되는 인덱스로 각 파일의 **이름과 한 줄 목적만** 파악합니다 — 전체 내용을 미리 읽지 않습니다. 각 파일의 내용은 관련 작업을 **시작하기 직전에** 읽고, 그 내용을 **예외 없이** 따릅니다. 카테고리 지침 위반은 가장 무거운 결함으로 취급합니다: 즉시 작업을 멈추고 정상화하기 전에는 다음 단계로 넘어가지 않습니다.

- 세션 시작 시 주입된 워크플로 진입 규칙이 "먼저 진입 분기를 제시하라"고 요구하면, 새 코드 변경 신호에서는 그 분기 제시가 카테고리 내용 읽기를 포함한 어떤 탐색·작업보다 **먼저**입니다. 분기 제시는 "작업 시작"이 아니므로 이 카브아웃은 위 강제와 어긋나지 않습니다 — 카테고리 내용 읽기는 경로가 정해진 뒤로 미룹니다.
- 어느 카테고리가 관련되는지 모호하면 후보 파일을 모두 확인합니다. "관련 없을 것 같다"는 추정으로 건너뛰지 않습니다.
- 룰이 현재 작업 방식을 바꾸면 즉시 따릅니다. "이미 시작한 작업"은 면제 사유가 아닙니다.
- 작업을 시작하기 직전에 관련 카테고리 내용을 확인하지 않았다면, 그 자체가 결함이며 다음 도구 호출 전에 확인합니다.

# 사용자 상호작용 규칙

사용자에게 결정·승인·선택·해명을 요청할 때는 현재 환경에서 제공하는 구조화된 사용자 질문 기능을 우선 사용합니다. 해당 기능을 사용할 수 없는 환경에서만 간결한 직접 질문을 사용하며, 자유 텍스트에 같은 질문을 반복하지 않습니다.

## 발신 전 점검

마지막 문단에 아래 신호가 있으면 질문 부분을 구조화된 사용자 질문 기능으로 분리합니다.

- `?`, `Y/N`, `A vs B`
- "...할까요", "...할지", "...주세요", "알려주세요", "결정해주세요", "선택해주세요", "어떻게 할까요", "괜찮을까요"
- "원하시면 ...", "필요하시면 ...", "괜찮으시면 ..."처럼 실제로는 결정을 요청하는 표현

## 트리거

- 두 개 이상의 선택지·옵션 제시
- 결정·승인·선호 요청
- 모호한 요구의 의도 확인
- 보고·요약·완료 발표 뒤 다음 단계를 묻는 경우

한 턴에 여러 결정 질문이 있으면 한 번에 최대 4문항까지 묶습니다.

## 예외

- 순수 단방향 보고: 결과·진행 상황만 알리고 결정·승인·다음 단계 요청이 없을 때.
- 사용자가 자유 서술 답변을 명시적으로 원하는 경우.

보고와 결정 요청이 섞이면 보고는 자유 텍스트로, 결정은 구조화된 사용자 질문 기능으로 분리합니다.

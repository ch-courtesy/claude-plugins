# create-task

**무엇** — 외부 작성자(`feature` 인터뷰 작성자, `fix` 정적분석 작성자)가 떠 준 자기완결적 **태스크 본문**
(목표·배경·제안·검증 계획·완료 기준)을 받아 선택된 백엔드(filesystem/github-project/beads)에 태스크로
**등록**하는 **등록 프리미티브**. 본문이 곧 SPEC이며 별도 SPEC 파일은 만들지 않는다.

**무엇을 안 하나** — 인터뷰·범위 분해·정적분석 같은 **작성 로직을 갖지 않는다**(그것은 작성자
`feature`/`fix`의 몫). 받은 완성 본문을 등록하고, **등록-후 상태 전이**(완성→backlog / 미해결 잔존→in_design)를
소유하며, 본문 갱신은 백엔드 `set_body` 동사에 위임한다.

**언제** — 작성자가 떠 준 본문을 무인 실행 가능한 태스크로 백로그에 올릴 때. 등록된 태스크는
`execute-task`(단일 실행)나 `workflow-task`(무인 드레인)가 실행한다.

**호출** — `Skill(skill="create-task", args="<제목>\n\n<태스크 본문>")`.

**자기완결** — 컨슈밍 프로젝트 `rules/`나 다른 스킬에 의존하지 않는다. 백엔드 계약은 플러그인
`task-backend/contract.md`가 단일 출처. 상세는 `SKILL.md`를 따른다.

# using-autopilot

autopilot이 설치된 프로젝트의 워크플로 진입점 스킬. 새 코드 변경 요청을 구현·탐색보다 **먼저** SPEC 작성 단계로 라우팅한다.

## 무엇인가
세션에서 새 코드 변경 신호를 감지하면 그 작업을 SPEC 우선 파이프라인으로 보내는 라우팅 규칙이다. 기능 의도는 `autopilot:spec`, 버그·증상·실패 테스트는 `autopilot:repair`로 분기한다. 일반적인 brainstorming-first 지침을 이 범위에서 대체한다.

## 언제 활성화되나
autopilot 설치 프로젝트의 세션 시작 시, 그리고 "X 만들어줘 / 고쳐줘 / 이 SPEC 구현 / 지침 수정" 같은 새 코드 변경 신호가 보일 때. 순수 질의응답·읽기·검색·운영 명령 등은 대상이 아니다.

## 어떻게 호출하나
```
Skill(skill="using-autopilot")
```
자세한 트리거·예외·분기·합리화 차단 규칙은 [`SKILL.md`](./SKILL.md)가 단일 출처다. 이 문서는 그 계약의 사람용 요약이며 세부는 복제하지 않는다.

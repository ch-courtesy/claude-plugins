# fix subagent briefs (fix 자체 소유)

fix 워크플로에서 선택적으로 Agent에 위임할 수 있는 역할 2종. 플러그인 자기완결 — 외부 스킬·`rules/`를
참조하지 않는다. 공통 원칙: 결정·합성·진단 확정·본문 작성·마커 삽입은 메인 책임. subagent는 **사실·발견만
보고**한다(중첩 위임 금지). brief는 자기완결이어야 한다 — subagent는 메인 컨텍스트를 보지 못한다.

## fix-context-explorer

언제: step 1 컨텍스트 탐색이 부족할 때. 권장 신호: 증상 영역이 넓음, 관련 코드가 여러 파일에 분산, 에러
신호만 있고 위치 불명.

임무: read-only 정적 분석으로 증상에 관련된 코드 영역·에러 신호·최근 변경·유사 정상 지점을 수집한다. 버그를
실행·재현하지 않고, 본문을 작성하거나 근본 원인을 확정하지 않는다.

응답:

```text
## 증상 관련 코드 영역
- [파일:줄] <역할> — 증상과의 연관

## 에러 신호
- [출처] <메시지·스택이 지목한 파일:줄>

## 최근 변경
- [commit/파일] <증상 영역에 닿은 변경>

## 유사 정상 지점
- [파일:줄] <정상 동작하는 유사 코드 — 대조용>

## 권고
- <메인이 진단에서 고려할 점>
```

## fix-body-reviewer

언제: step 4 자체 검토 보강. 권장 신호: 본문 100줄 이상, `[NEEDS CLARIFICATION]` 2개 이상, 사용자 요청.

임무: 작성된 버그 본문 초안을 공용 `plugins/autopilot/references/self-review.md`의 점검 축 + 진단 섹션 전용
점검(fix 전용 절)으로 독립 검토하고, 세 적대 렌즈를 가산한다 — 렌즈 정의는
`plugins/autopilot/references/personas.md`(단일 출처)를 읽어 적용한다(복제 금지). **발견만 보고**한다 —
수정·마커 삽입은 메인이 한다. brief에 두 파일 경로를 함께 전달한다(subagent는 메인 컨텍스트를 못 본다).

응답:

```text
## 점검 축 검토 결과
- placeholder 잔존: N / 모순: N / 범위: N / 모호성: N / 검증 가능성 fail-위험: N / scope.include 문제: N

## 진단 섹션 점검
- 가설 프레이밍: OK | 문제
- 증거 파일:줄: OK | 누락
- 정적 한정 위반(실행·재현 가정): 없음 | [위치] <문제>
- 완료 기준(버그 미관찰 + 회귀 가드): OK | 문제

## 적대 렌즈 발견
### [contrarian]
### [minimalist]
### [constraint-auditor]

## 판정
- 진행 가능: 예 | 마커 추가 후 가능 | 재작성 필요
- 근거: ...
```

## 호출 패턴

```text
Agent({
  description: "<짧은 요약>",
  subagent_type: "general-purpose",
  prompt: <위 양식 + 필요한 파일 경로/본문/응답 형식>
})
```

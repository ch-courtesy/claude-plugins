# review

한 작업의 변경(diff)을 여러 독립 관점으로 리뷰해 단일 머신리더블 판정·근거 있는 지적·재작업 브리프를 산출하는 **원샷 리뷰 생산자** 스킬.

- **무엇** — diff 를 4 lens(SPEC 준수·정확성/보안·회귀/이력·가이드라인 준수)로 독립 리뷰하고, 결정적 중재 게이트가 `approve`/`request_changes`/`unavailable` 단일 판정을 낸다. 반복·승인·머지는 소유하지 않는다.
- **언제** — 코드 리뷰·PR 리뷰·변경 검토가 필요할 때, 또는 머지 전 변경을 검증하고 싶을 때.
- **호출** — `Skill(skill="review", args="<subcommand> [<args>]")` (`run`/`status`/`list`).

리뷰 관점·중재 게이트·판정 규칙·하니스 역할·불변식 등 동작 명세는 단일 출처인 [`SKILL.md`](./SKILL.md)를 참조한다.

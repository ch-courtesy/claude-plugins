# clarity 점수 (정량 명확도 리드아웃)

명확화 인터뷰가 **잠정 종결**에 이르렀을 때 SPEC 의도의 명확도를 메인 에이전트가 산정하는 경량 점수의 **단일 출처**다. 차원·척도·산정 방식·권장 임계·보완 규칙을 이 한 곳에 정의한다.

clarity 점수는 **소프트 권고**다. SPEC 작성을 차단하거나 자동 게이트로 동작하지 않는다. 기존 `[NEEDS CLARIFICATION]` 미해결 마커 시스템과 그 마커에 의한 자율 실행 차단을 **보완할 뿐 대체하지 않는다** — 점수가 낮아도 사용자가 충분을 선언하면 SPEC 작성으로 진행하고 미해결 항목은 마커로 남긴다.

## 차원

핵심 3차원을 항상 산정한다. 초안 규모·복잡도에 따라 보조 2차원을 선택적으로 더한다.

| 차원 | 묻는 것 |
|---|---|
| 목적 | 변경의 목적(왜)이 모호성 없이 잡혔고 **SPEC 문서의 목적 섹션에 문장으로 남았는가** |
| 제약 | 구속력 있는 제약이 충분히 식별되었는가 |
| 성공기준 | 완료 조건이 관찰·검증 가능한가 |
| (보조) 범위 | 포함/제외 경계가 분명한가 |
| (보조) 위험 | 주요 위험과 완화가 드러났는가 |

목적 차원은 단순히 인터뷰에서 왜가 합의됐는지뿐 아니라 그 목적(왜)이 발행 SPEC의 **목적 섹션에 문장으로 보존**됐는지를 본다 — 휘발하면 점수가 낮다. (차원·척도·임계 구조 자체는 그대로 유지한다.)

## 척도

차원별 0–5 정수 척도(스케일). 0=전혀 불명, 5=구현 스킬이 중간 질문 없이 수행 가능할 만큼 명확. 점수는 **메인 에이전트의 추론만으로 산정**한다 — 새 런타임·엔진·의존성을 요구하지 않는다(무인프라). 외부 채점기·모델 호출·도구를 도입하지 않는다.

## 리드아웃과 권장 임계

잠정 종결 시 차원별 점수를 사용자에게 리드아웃으로 제시한다.

```text
clarity readout
- 목적:     N/5
- 제약:     N/5
- 성공기준: N/5
```

**권장 소프트 임계**: 핵심 3차원이 모두 4/5 이상. 한 차원이라도 임계 미만이면 추가 명확화 라운드를 **현재 런타임의 구조화 질문 기능으로 권고**한다 — 자유 텍스트 질문으로 권고하지 않는다. 사용자가 추가 명확화를 거부하거나 충분을 선언하면 점수와 무관하게 SPEC 작성으로 진행한다.

## 보완 규칙

clarity 점수는 미해결 마커를 대체하지 않는다. 종결 후 남는 모호 항목은 종전대로 `[NEEDS CLARIFICATION: <질문>]` 마커로 SPEC에 남고, 그 마커가 자율 실행을 차단하는 동작도 그대로 유지된다. clarity 점수는 "마커를 남기기 전에 한 라운드 더 물을 가치가 있는가"를 사람에게 묻는 소프트 신호일 뿐이다.

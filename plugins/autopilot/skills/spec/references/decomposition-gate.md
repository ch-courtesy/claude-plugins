# 범위 분해 게이트 (optimized)

step 3 뒤 사용자 의도가 다중 독립 서브시스템인지 검사한다.

## 감지 신호

2개 이상이면 다중 가능성이 높다.

- 접속사 다중: "그리고", "+", "and" 등이 서로 다른 명사를 잇는다.
- 명사 영역 다양성: auth/payment/notification/analytics처럼 도메인이 다름.
- 파일 트리 분산: 관련 코드가 3개 이상 최상위 디렉터리에 분산.
- 테스트 셋 분리: 부분별 verify 명령이 다름.

## 질문

다중 감지 시 `AskUserQuestion`으로 묻는다.

- (a) 분해: 첫 영역만 본 SPEC에서 진행, 나머지는 별도 task-id.
- (b) 단일 강행: Risks에 "다중 영역이나 사용자 확인 후 단일 task 진행" 기록.
- (c) 다른 task-id로 시작: 현재 호출 abort.

(a) 선택 시 SPEC 끝에 후속 task 메모를 남긴다. (b)는 항상 제공해 위양성에 대응한다.

# pre-clarification (optimized)

검증 실패 또는 자연어 직접 입력을 즉시 abort하지 않고 안전하게 task-id/범위를 확보하는 절차.

## 1.1 routing

`AskUserQuestion` 3옵션:

- `(a)` task-id 재입력 후 재시도
- `(b)` 사전 명확화 라운드 진입
- `(c)` 종료

`(c)` 또는 취소는 어떤 산출물도 작성하지 않는다. 자유 텍스트로 "다음 단계: Skill(...)" 안내 금지.

## 1.2 사전 명확화

step 5 명확화 메커니즘을 task-id 확보 전으로 앞당겨 재사용한다. 별도 phase나 모듈을 만들지 않는다. 한 번에 한 질문으로 `문제·목표·범위·제약`을 수집한다.

종결 조건:

- 충분히 좁혀짐
- 사용자가 취소
- 마일스톤 규모로 판정

취소 시 산출물 미작성. 단일 task로 수렴하면 프로젝트 태스크 관련 지침으로 task를 만들고 반환된 task-id를 그대로 사용해 step 2부터 재개한다. 마일스톤 규모면 PRD 스킬 호출 여부를 `AskUserQuestion`으로 명시 승인받고 milestone-id를 전달한다.

# spec

명확화 인터뷰로 자기완결적 SPEC 문서를 작성하고 구현 스킬을 추천하는 경량 스킬. 코드·머지·이슈·브랜치 등 외부 상태는 만들지 않으며 산출물은 SPEC 문서뿐이다.

## 무엇인가
새 기능·동작 추가, 지침·문서 작성·수정, 기존 SPEC 구현 같은 코드 변경 의도를 받아 명확화 인터뷰로 의도·요구사항·설계를 탐색하고, 구현 스킬(`autopilot:dispatch`)이 중간 질문 없이 수행할 수 있을 만큼 자기완결적인 SPEC 문서를 산출한다.

## 언제 활성화되나
무언가를 새로 만들거나 동작·지침을 바꾸려 할 때의 첫 단계. 버그·증상·실패 테스트는 형제 스킬 `autopilot:repair`가 담당한다.

## 어떻게 호출하나
```
Skill(skill="spec", args="<자연어 task 설명>")
Skill(skill="spec", args="--resume <spec-path>")
```

## 포인터
- 워크플로 1–7단계·호출 계약·옵트인 핸드오프 규칙: [`SKILL.md`](./SKILL.md) (단일 출처)
- 인터뷰·점수·템플릿·자체 검토 등 세부 자산: [`references/`](./references/)

이 문서는 사람용 요약이며 세부 절차·규칙은 복제하지 않는다.
